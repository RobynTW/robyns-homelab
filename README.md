# Robyn's Homelab

A personal homelab focused on **Linux, networking, virtualisation, self-hosting, and learning**.

## Architecture

**Dell OptiPlex 3060**

* Proxmox
* Pi-hole + Unbound
* NetBird
* Jellyfin
* Nginx
* Beszel
* Uptime Kuma

**Dell OptiPlex 9020** *(planned)*

* NAS / NFS storage
* Pterodactyl
* Game servers

**Future**

* Media automation stack
* Managed switch
* pfSense
* VLAN segmentation
* Homarr
