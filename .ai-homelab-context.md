Key files:

- `/opt/homepage/config/settings.yaml`
- `/opt/homepage/config/widgets.yaml`
- `/opt/homepage/config/services.yaml`
- `/opt/homepage/config/custom.js`
- `/opt/homepage/config/custom.css`

Settings include the local background and `iconStyle: theme`.

Top widgets include System, Storage, and a GitHub logo linking directly to `https://github.com/RobynTW/robyns-homelab`. The redundant Developer/GitHub bookmark was removed.

Service groups are Infrastructure, Network, Media, Gaming, and Monitoring.

PVE-1/PVE-2 use custom API endpoints on port 61209 backed by `/usr/local/bin/homepage-stats.py` and `/etc/systemd/system/homepage-stats.service`.

The custom JS has no MutationObserver, recursion, or polling. A previous MutationObserver implementation caused severe browser/PC lag and was removed.

Custom CSS provides the three-column layout, glass cards, larger headings, responsive behaviour, Network positioning, GitHub right alignment, and the bottom visual cap.

The Network group's vertical offset is manually tuned and should not be casually overwritten.

The bottom cap is cosmetic; do not destabilise the dashboard to perfect its stacking unless explicitly requested.
