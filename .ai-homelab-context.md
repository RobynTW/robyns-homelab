## 1. PROJECT

**Name:** Robyn's Homelab
**Primary domain:** `robynshomelab.dev`
**GitHub repository:** `RobynTW/robyns-homelab`

### Core goals

* Build a practical self-hosted homelab around Proxmox.
* Keep services appropriately separated between VMs and LXCs.
* Use Nginx as the reverse proxy for web services.
* Use Cloudflare for authoritative public DNS and DNS-01 certificate validation.
* Use NetBird for secure remote/LAN access without router port forwarding.
* Build storage/NFS infrastructure on the Dell OptiPlex 9020.
* Run Pterodactyl for game-server management.
* Eventually deploy the media stack.
* Eventually deploy Homarr as a central dashboard.
* Maintain accurate GitHub documentation for future AI continuity.

### Working principles

* Preserve working infrastructure.
* Do not rebuild working services simply because documentation is incomplete.
* Make changes incrementally.
* Verify current state before destructive or broad changes.
* Clearly distinguish `DEPLOYED`, `IN PROGRESS`, and `PLANNED`.
* Do not put credentials, API tokens, passwords, setup keys, private keys, cookies, or other secrets in GitHub or this file.
* When documentation conflicts, current deployed state takes precedence over historical plans.
